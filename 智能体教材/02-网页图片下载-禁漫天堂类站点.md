# 02｜网页图片下载：禁漫天堂类站点的完整链路（API 鉴权 + CDN 换源 + 切片还原）

> 场景：下载漫画站点章节图片（WebView 加密接口 + CDN 拦截 + 切片混淆图）。
> 结论：**网络断连/域名被拦 ≠ 无解**——按"移动端 API → 换 CDN 域名 → 真浏览器"的顺序找替代路径；接口加密与图片切片都有可验证的还原算法。

## 背景
- 目标：把站点章节的图片批量下载到本地并还原成完整可看的图片。
- 现象：直连图片 URL 经常断连/超时（域名被拦）；直接保存的图片是"切片混淆"图，无法观看。

## 根因（两条关键规律）
1. **网络断连/重置/超时 ≠ 无解**：页面域名被拦 ≠ 所有入口都被拦。先找**移动端 API**（接口域名通常比网页宽松），再**换 CDN 域名**（保留 path+query 只换 host），最后用**真浏览器**（Edge/Playwright）。
2. **图片是切片混淆存储**：下载到的图片是"竖向切条 + 反转重拼"的混淆图，必须按算法还原。

## 正确做法（已验证配方）

### 1) 章节接口 + 鉴权
- 接口：`GET https://www.cdngwc.cc/comic_read?id=<章节id>`
- 请求头：Android WebView UA + `origin: http://localhost` + `x-requested-with: com.a7m3p9xv.t6qk2z8.app`
- 鉴权：`Tokenparam: "{ts},2.0.26"`；`Token: MD5(ts + "185Hcomic3PAPP7R")`（hex）

### 2) 解密
- 响应：`{ data: base64(AES-256-ECB, PKCS7) }`
- 密钥 = `MD5(ts + secret)` hex 字符串的 UTF-8 字节（32 字节）
- 解密后：`{ id, name, total_page, scramble_id, images: [{page, image}] }`

### 3) CDN 换源（域名被拦时，保留 path+query 只换 host）
- 候选 host：`cdn-msp2.jmapinodeudzn.net` / `cdn-msp3.jmapinodeudzn.net` / `cdn-msp2.jmapiproxy2.cc` / `cdn-msp2.jmapiproxy1.cc`
- 下载头：`UA: Mozilla/5.0`、`referer: https://18comic.vip/`、`accept: image/webp`

### 4) 切片还原（已验证）
- `filename` 取**不含扩展名的 basename** 参与 md5（接缝检测实验 26:6 证实）；
- `power` 按 id 区间取 `10/10/8`；
- `mod = md5(photo_id + basename) 末字符 % power`；余 0 不切，否则 `N = (mod+1)*2`；
- 还原 = 竖向切 N 条、反转顺序重拼（sharp 库）。
