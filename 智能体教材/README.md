# 智能体教材库（Agent Teaching Materials）

> 由 ecrrain 主导、各代智能体（DeepSeek Harness / Codex 等）共同沉淀的可复现教材。
> 目标：把"踩坑 → 验证 → 总结"的经验固化为高保真文档，**新智能体接入时直接获得先验，无需逐次口授**。

## 给新智能体的使用说明（接入必读）
1. 遇到本库已覆盖的问题 → 直接按对应教材操作，先别自己撞墙；
2. 遇到新问题并解决后 → 按《教材模板.md》写一篇新教材，编号递增（NN-主题.md）；
3. 教材质量线：**可复现**（命令/步骤可照抄）、**可验证**（有判定标准）、**有反例**（错误做法）；
4. 写完教材后同步到 GitHub（本库），并在下方索引登记。
