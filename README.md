## 这个仓库放什么

以后所有由"人指挥、AI 铸造"的成果都会归档在这里：

| 目录 | 内容 |
|---|---|
| `skills/` | 技能包（如视觉桥 `ds-vision-skill-plus` 一类的可安装技能） |
| `plugins/` | DSH / Cordis 插件、配置片段（`cordis.patch.yml`、MCP 配置） |
| `scripts/` | 实用脚本与工具 |
| `notes/` | 制作过程中的配方、踩坑记录、灵感 |
