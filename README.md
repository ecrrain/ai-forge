## 📚 智能体教材库

> 这是本仓库最有潜力的部分：把"踩坑 → 验证 → 总结"的经验固化为**高保真教材**，让新智能体接入时直接带着先验上岗，不必每代都从零撞墙——**教材就是给 AI 的"教科书"**。

- 📖 入口：[`智能体教材/README.md`](智能体教材/README.md) —— 使用说明 + 教材索引
- 📄 规范：[`智能体教材/教材模板.md`](智能体教材/教材模板.md) —— 新教材按此格式编写
- ✅ 质量线：可复现（命令可照抄）、可验证（有判定标准）、有反例（错误做法）

| 编号 | 主题 | 一句话要点 |
|---|---|---|
| 01 | [TIA Portal 博途：GUI 打开到用户可见桌面](智能体教材/01-TIA-Portal-博途-可见桌面打开.md) | agent 环境 GUI 落在隐藏桌面，用 schtasks /it 投到可见桌面 |
| 02 | [网页图片下载：禁漫天堂类站点完整链路](智能体教材/02-网页图片下载-禁漫天堂类站点.md) | 断连≠无解：移动端 API → 换 CDN 域名 → 真浏览器；加密接口 + 切片还原有可验证算法 |

> 🌱 愿景：集结上千人用 AI 的思路与经验，精炼成教材库喂给新智能体——不亚于一次再训练，就像人类小孩上学，站在前人精炼的智慧上。当前先积累真正帮到人的教材，再召集大家共建。

## 这个仓库放什么

以后所有由"人指挥、AI 铸造"的成果都会归档在这里：

| 目录 | 内容 |
|---|---|
| `skills/` | 技能包（如视觉桥 `ds-vision-skill-plus` 一类的可安装技能） |
| `plugins/` | DSH / Cordis 插件、配置片段（`cordis.patch.yml`、MCP 配置） |
| `scripts/` | 实用脚本与工具 |
| `notes/` | 制作过程中的配方、踩坑记录、灵感 |
| `智能体教材/` | 可复现的经验教材（见上方"智能体教材库"） |
